# Simulacion-Monte-Carlo-y-Optimizacion-de-Portafolios-de-Inversion
Construcción y evaluación de un portafolio con activos financieros reales mediante simulaciones Monte Carlo, métodos de reducción de varianza y métricas de riesgo (VaR y CVaR). Se incluyen pruebas de estrés y optimización de pesos para mejorar la relación riesgo-rendimiento.
